# تحليل الفجوات التنافسية — رواق ضد رشد (rushd.tech)

> تاريخ الإعداد: 2026-10-31 · المصادر: rushd.tech/ar و rushd.tech (محمّلة فعليًا) — لا صفحات فرعية أو توثيق عام أو أسعار منشورة لديهم.

## 1. ملخص المنافس (رشد)

- **التموضع:** "البيئة التشغيلية الرقمية لسوق الضيافة" — Channel Manager + مدفوعات + سوق موردين + شبكة مشغلين.
- **القنوات (5 فقط):** Airbnb, Booking.com, Expedia, Gathern, Agoda — بمزامنة معلنة < 60 ثانية.
- **التوافق المحلي:** فواتير ZATCA، الإبلاغ للرصد السياحي وشموس، Rushd Pay (مدى/Apple Pay عبر الإنماء)، أقفال TTLock فقط.
- **التسعير:** غير منشور إطلاقًا — نموذج بيع مباشر عبر WhatsApp وعرض توضيحي. برنامج إحالة بعمولة.
- **الجمهور:** مضيفو شاليهات ومزارع وشقق + مشغلون 50+ وحدة.
- **نقاط القوة:** عمق الامتثال السعودي (ZATCA/شموس/مدى)، لعب النظام البيئي (مدفوعات+سوق+مشغلون)، دعم مؤسسي (CODE، NTDP، جادا).

## 2. فجوات المنافس (فرصنا)

| الفجوة لدى رشد | فرصتنا التنافسية |
|---|---|
| لا صندوق رسائل موحد (WhatsApp Business/OTA inbox) | Unified Inbox + ردود آلية (P1) |
| تسعير بدائي: خصم 12% ثابت لليالي الشاغرة | محرك تسعير قواعدي حقيقي (مواسم/عطل/إشغال) ثم ديناميكي (P2) |
| لا أسعار معلنة ولا شهادات عملاء | شفافية كاملة: أسعار منشورة + باقة تجريبية ذاتية |
| بوابة مالك ضمنية (عبر شبكة المشغلين) | بوابة مالك مستقلة read-only بتقارير دورية |
| لا owner statements/تسويات مالية رسمية | لوحة مالية + كشوف مالك (P1) |
| أقفال TTLock فقط | توسيع دعم الأقفال لاحقًا (P2) |
| لا واجهات برمجية عامة/توثيق | Webhooks + API v1 من اليوم الأول |
| موقع من صفحة واحدة (بصمة SEO ضعيفة) | محتوى SEO عربي + صفحات تحويل لكل ميزة |

## 4. الاستنتاج

ميزة رشد الحقيقية هي سبق الامتثال السعودي وشراكاتهم المالية. لا ننافسهم على الادعاء بل على:
1. **الصدق التقني**: مركز تكاملات يعرض الحالة الفعلية لكل ربط — لا تكامل "مفعّل" إلا مختبر.
2. **شفافية تجارية**: أسعار معلنة، تجربة ذاتية، بلا موظف مبيعات.
3. **جوهر تشغيلي متين**: منع تعارض على مستوى قاعدة البيانات، تقويم موحد، حجز مباشر، بوابة مالك.
4. **بنية جاهزة للقنوات**: Integration Engine تُفعّل ثنائية الاتجاه فور توفر API رسمي أو شراكة Channel Manager (انظر `channel-manager-evaluation.md`).
